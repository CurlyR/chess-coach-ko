# Chess.com 코치 한국어

v1.3.9: `/daily` 및 날짜별 일일 퍼즐 화면에서 번역이 실행되지 않던 경로 누락을 수정했습니다. 오류 기록에도 일일 퍼즐과 확인된 완료 상태를 구분해 저장합니다. 실제 관찰된 완료 대사를 추가했으며, 이미 한국어인 상태 문구를 영어 누락 수에 포함하지 않습니다.

v1.3.8: 코치 원문의 문장 내부 조각을 조합해 번역합니다. 앞부분 44종과 매그너스 행동 조각 794종·히카루 792종을 지원하며, 앞뒤 문장과도 연결합니다. 코치·행위자·기물 순서와 한국어 조사를 유지하고, 모르는 조각은 임의로 번역하지 않습니다. 별도 리뷰 로딩 목록의 58문구도 반영했습니다. 이는 모든 신규 대사의 번역 완료를 뜻하지 않습니다.

v1.3.7: `/game/숫자` 대국 주소에서도 번역과 상태 버튼이 표시되도록 수정했습니다. 대국 종료 화면의 식별·오류 기록도 지원하며, 해당 승리 안내 문구를 검수했습니다. 리뷰 해설의 누락 문장을 추가하고, 여러 문장으로 검수된 번역도 복합 해설에 조합하도록 개선했습니다.

현재 버전: **1.3.9**. 우하단 상태 버튼에서 실행 중인 버전을 확인할 수 있습니다.

v1.3.6에서는 공통·기본 대사 검수 목록 **10,593개 전체를 원문과 대조해 검수하고 반영했습니다.** 이 목록의 미검수·보류 항목은 **0개**입니다. v1.3.5에서 남았던 7,241개도 모두 처리했으며 매그너스·히카루 양쪽 사전에 적용했습니다. 기물 소유자, 교환 후 손익, 핀과 디스커버드 어택, 승격·엔드게임, 오프닝 및 경기 결과 설명을 포함합니다.

v1.3.4에서는 11월 23일 접수된 39건(중복 제외 29문구)의 미번역·오역을 수정했습니다. 리뷰 공통 설명, 로딩 문구, 상식 문구와 복합 해설의 누락 문장을 추가하고, 기물이 달라지는 동일 표현도 정확 일치 사전으로 보완했습니다. 백랭크 메이트 오역도 수정했습니다. 자동 업데이트 및 오류 기록 설정은 유지됩니다.

v1.3.3에서 처리한 검수 대기 목록의 고유 원문 **11,143개를 모두 직접 대조·검수했습니다**. 추가 확인 대상 1,940개와 자동 검사만 완료됐던 문구까지 처리해, 이 목록의 미검수·보류 항목은 0개입니다. 이미 승인된 번역을 다시 전수 검토한 것이 아니라 남아 있던 검수 목록을 마무리했습니다.

기물 이름과 소유자, 핀·디스커버드 어택·교환·승격, 시간승과 판세 변화, 기보와 한국어 조사를 수정했습니다. 색상 템플릿은 백·흑이 들어간 정확한 문구로 확장하며, 상대 색상은 반대로 유지합니다. 원문의 색상 변수를 화면에 노출하지 않습니다.

이는 현재 검수 목록의 완료를 뜻하며 Chess.com 전체 문구의 번역 완료를 뜻하지 않습니다. 사전에 없는 새 문구는 여전히 영어로 나올 수 있고 오류 기록으로 수집됩니다.

매그너스·히카루의 코치 말풍선을 로컬 번역 사전으로 표시하는 비공식 Tampermonkey 스크립트입니다. API 키가 필요하지 않습니다. 기존 사전에는 이번 검수 목록 밖의 기계번역도 포함되어 있습니다.

## 설치 · 기존 버전 업데이트

Chrome 또는 Firefox에 Tampermonkey가 설치된 상태에서 아래 링크를 열고 설치/업데이트를 누르세요.

[한국어 코치 설치 / 업데이트](https://raw.githubusercontent.com/CurlyR/chess-coach-ko/main/coaches-ko.user.js)

각 브라우저에서 한 번씩 설치한 뒤 Chess.com을 새로고침하세요. 예전 스크립트와 이름·네임스페이스를 유지하므로 같은 스크립트로 업데이트됩니다. 중복 설치가 있다면 하나만 켜주세요.

## 자동 업데이트

Tampermonkey의 스크립트 업데이트 확인이 활성화되어 있으면 정해진 확인 주기에 따라 새 버전을 확인합니다. 즉시 필요할 때는 Tampermonkey의 업데이트 확인 기능을 사용하세요. 다운로드 후에는 Chess.com을 새로고침하세요. 브라우저 설정에 따라 확인이 필요할 수 있습니다.

GitHub에 새 버전이 배포되어야 업데이트됩니다. 개발 PC의 파일을 수정하는 것만으로 배포되지는 않습니다.

## 범위

게임 리뷰, 대국 종료, 퍼즐 및 코치와 플레이의 일치 문구를 지원합니다. 레슨은 제외합니다. 사전에 없거나 검수 보류된 문구는 영어로 유지합니다. 우하단에서 번역을 끄거나 오류 기록을 확인할 수 있습니다.

## 비공개 오류 기록 (v1.3.0)

미번역은 자동 기록하고, 잘못된 번역은 말풍선의 **신고**를 눌러 기록합니다. 원문·표시된 번역·발생 시각·화면 종류·코치 식별 근거·확인 가능한 URL의 수 번호 단서·실제로 관찰된 전후 문구를 함께 보관합니다. 코치 이름이나 수 번호를 확인할 수 없으면 미확인으로 남깁니다. URL의 move 값은 사이트가 제공한 값 그대로이며 실제 수 번호로 추정 변환하지 않습니다.

자동 전송은 기본적으로 꺼져 있습니다. 개인 비공개 Google 시트의 **연결 안내** 탭에서 연결 링크를 열고 동의한 브라우저에서만 작동합니다. 개인 연결 정보는 이 저장소에 포함되지 않습니다. 각 Chrome/Firefox에서 한 번씩 연결해야 합니다. 새 저장·전송 권한으로 인해 Tampermonkey가 업데이트 확인을 요구할 수 있습니다.

연결 후 약 30초마다 전송을 시도하며, 실패하면 기록을 보관하고 재시도합니다. 브라우저를 닫아도 남아 있으며 Chess.com에 다시 들어오면 재시도합니다. 브라우저 저장소에는 최대 500개를 보관하고 오래된 전송 완료 기록부터 정리합니다. 미전송 기록으로 가득 차면 ‘저장 공간 가득 참’을 표시합니다. 사이트가 초기화되거나 확장 프로그램 데이터를 삭제하면 로컬 기록이 사라질 수 있습니다.

계정명·상대 이름·전체 대국 URL·전체 기보·쿠키를 별도 수집하지 않습니다. 전송은 Google Apps Script의 지정된 수신 주소에만 이루어집니다. 우하단 **기록** 버튼에서 자동 전송을 끄거나 기록을 내려받을 수 있습니다. 기록 수집이 번역 오류의 자동 수정이나 실시간 검수를 의미하지는 않습니다.

Chess.com과 제휴하거나 공식 지원받는 프로젝트가 아닙니다. Chess.com의 명칭과 원문 콘텐츠에 대한 권리는 각 권리자에게 있습니다.

## 코치 식별 수정 (v1.3.0)

애니메이션 코치도 현재 페이지에서 새로 갱신된 Chess.com의 확정 코치 설정으로 구분합니다. 코치 선택창에서 미리 선택한 항목이나 오래된 계정 캐시는 사용하지 않습니다. 정보가 없거나 여러 계정 정보가 충돌하면 미확인으로 유지합니다. 식별 근거는 current_coach_resource로 기록되며 저장 키와 계정 식별자는 전송하지 않습니다. 과거 Unknown 기록은 추측해서 바꾸지 않습니다.

## 화면·기록·번역 개선 (v1.3.0)

수집된 미번역 20건, 전후 문구 22건, 준비 화면 인사 1건으로 총 43개 문구를 직접 검수했습니다. 화면은 코치와 플레이/컴퓨터/온라인/퍼즐/분석/리뷰로 구분하며, 확인 가능한 준비·요약·수별 설명·종료 단계를 별도로 기록합니다. 확인할 단서가 없으면 unknown으로 남깁니다. 화면의 수 번호와 URL move 값은 구별합니다. 전체 URL이나 상대 이름은 보내지 않습니다.

전후 문구는 실제 기보의 연속 수가 아니라 화면에서 관찰한 순서입니다. 리뷰의 수를 건너뛰거나 되돌리면 연결하지 않습니다. 전송 후 나타난 다음 문구는 소급 추가되지 않습니다. 이전 버전 기록의 코치/화면은 추측해서 복원하지 않습니다. 신고 버튼에서 의미·기물·관점·표시·식별 중 문제 유형을 고를 수 있습니다.
